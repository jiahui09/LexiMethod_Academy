# 课程内容风格指南（写作规范）

适用于新课程体系全部文案字段（claim / blocks / practice / question / 诊断报告 / 出门条 / 自测卡）。
本指南是《活人感写作》skill 对本项目的落地裁剪，写作时逐条执行。

## 1. 密度三件套（针对「文字密度大」）

每个单元只允许三类内容，超量即说明该拆单元：

1. **主张**（claim）：一句，≤40 字，先给结论，不铺垫。
2. **例子**（blocks 里的 example / demo）：一个，能交给交互演示的写 `demo` 块，不写成散文。
3. **动作**（practice 或 check）：一道题、一次点击、一句自检，单元必须以动手收尾。

单个 block 文本 ≤80 字；确实需要多说的，拆成 `list` 块（每项一行，≤30 字）。

## 2. 成稿禁令（命中即返工）

这些是修辞动作的禁令，换字面继续做同一个动作同样算命中：

- **禁翻案腔**：「不是……而是……」「不是A，是B」「你以为……其实……」「说到底」「答案恰恰相反」「A不重要，重要的是B」「与其说……不如说……」「看似……实则……」。判断直接从正面下，先给判断再给依据。
- **禁破折号**：`——`、`—`、`–` 一律不用。断句用句号，补充用逗号或括号。
- **禁提示性冒号**：「一句话总结：」「核心是：」「规则：」这类引出下文的冒号不用。冒号只用于引直接原话（教学数据里基本用不到）。标题里也不用冒号，改用副标题式短语或直接重写。
- **禁三项以上同构排比**：排比至多两项，第三项必须换说法或删。
- **禁黑话与抬价词**：说白了、说穿了、先说结论、值得注意的是、需要指出的是、更微妙的是、还有一层、从某种意义上说、赋能、抓手、闭环包装（「闭环」作为教学术语在旧文案里指拆解-核对流程，可保留使用，但不拿它抬价）。
- **禁动词名词化**：「完成了对流程的优化」写成「把流程改顺了」。
- **禁借喻包装抽象概念**：钥匙、底座、地基、浪潮这类隐喻不拿来包装方法论（文中若真在写实物不受影响）。
- **禁虚构素材**：不编用户见证、统计数据、研究结论。例词、IPA、规则必须真实，IPA 拿不准就查 `src/data/phonemes.ts`、`src/data/words.ts`，两处都没有就换词。

## 3. 数字纪律

- **本站规则数字可写**：1/3/7/14/30 天排期、≥80% 通过率、44px、10 秒划词、30% 联想占比。这些是本站的验收标准与设计规则，不是事实声明。
- **无出处的研究断言数字改定性**：「留存差 3 倍」「有效 2~3 倍」「转化率 1/5」这类精确倍数删掉，改为定性说法（「差距很明显」「只有一小部分会真正用起来」）。心理学常识（遗忘曲线先陡后平、自己产出比读到的记得牢、间隔复习比重读有效）可以讲，但不挂精确数字。
- 旧文案里已有的例词数量（24 前缀、30 词根等）是本站教学范围声明，保留。

## 4. 教程写法（针对教学效果）

- **开头先给收益**：学完能做到什么，第一单元就要说清（诊断开场的 lead 承担这个）。
- **步骤按依赖顺序**：后一单元用到前一单元的产出，不打乱。
- **每步写动作和可见结果**：「圈出元音核心，音节数当场能数出来」，不写「深入理解元音核心的重要性」。
- **原理讲到能处理常见变化即可**，不追求学术完备。
- **结尾不升华**：出门条打完就收，不谈认知、人生、时代。
- **给判断，给依据**：老师式的确定语气；确实有争议的写清适用边界，一句就够。

## 5. 字段级规范

| 字段 | 规范 |
|------|------|
| `claim` | 一句 ≤40 字，先结论，无冒号无破折号 |
| `example.text` | ≤80 字，含真实例词；可带 `speak`（朗读文本）与 `ipa` |
| `warning.text` | 误区/陷阱，一句 ≤60 字，点出后果 |
| `list.items` | 每项 ≤30 字，动词开头优先 |
| `practice.prompt` | 一句动作指令，说清做什么、过线标准 |
| `practice.debrief` | 一句讲评，说清为什么 |
| 诊断 `lead` | 一句，说清测什么、马上给什么报告 |
| `ScoreBand.verdict` | 一句人话诊断 + 指路（下一步去哪），≤50 字 |
| `exitTicket.intro` | 一句，说清测什么、当场出什么 |
| `selfCheck` | 5 条，是/否可答的自问句（「我能不看答案说出它的重音位置」） |
| 题目 `prompt` | 问题本体，具体、可当场作答 |
| 题目 `narration` | 不依赖画面也能懂的旁白（一句） |
| 题目 `hint` | 作答前可用的提示（一句，给方法不给答案） |
| 题目 `explain` | 揭晓后的原因讲解（判分当场展示，这是「当场揭晓」的落点） |
| 题目 `answer` | 标准答案字符串；选择题由 `choices[].correct` 标记 |

## 6. 语言与语气

- 全站中文；英文只出现在教学内容本身（例词、拼写组合、IPA）。
- 语气像一个有经验的老师在旁边说话，直接、具体、敢下判断；不用客服腔，不用营销腔。
- 对学习者称「你」。
- 现有素材（旧 `methods.ts` 中的规则、例词、误区）是已核实的教材底料，表达重写、事实沿用；发现事实疑点时改写或降级为定性表述。
