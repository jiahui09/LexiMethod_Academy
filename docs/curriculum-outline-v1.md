## 1. 新课程架构（宏观）

### 1.1 四段学习路径

```
第一段 通路    01 音标发音与拼写对应 ──→ 02 自然拼读法（音节与重音）
        ↓        「听到的音 ↔ 落笔的形」      「长词切块、能读出声」
第二段 拆解    03 词根词缀拆解法
        ↓        「长词 → 三个已知零件」
第三段 存入    04 语境记忆法 ──→ 05 联想记忆法 ──→ 06 间隔重复法
        ↓        「存进场景（主通道）」「难词拐杖（辅助）」「把复习排期化」
第四段 调用    07 主动输出法
                「被动词汇 → 主动词汇」
贯穿 · 收官   08 元认知训练（最后回来：对整条路径做总复盘）
```

**顺序调整提案（两处互换）：**

| 变更 | 现顺序 | 新顺序 | 理由 |
|------|--------|--------|------|
| 01 ↔ 02 | 自然拼读打头 | **音形对应打头** | 音素意识是切块的前提：先立「音↔形」双向通路，音节划分才不是画格子 |
| 04 ↔ 05 | 联想在前 | **语境在前** | 语境是人人必须的主存储通道，联想只是难词拐杖；先教主通道再教拐杖，且防止学生产生「谐音才是记忆法」的路径依赖 |

元认知保持第 8 门不动：它需要前 7 门积累的练习数据才能真复盘，放前面教了也没感觉；每课出门条末尾自带一句复盘钩子（「本轮最弱的一环是___」）做隐性贯穿。

### 1.2 每课在路径上的职责（一句话）

| # | 课程 | 路径职责 | 可观察目标（学完能做到什么） |
|---|------|----------|------------------------------|
| 01 | 音标发音与拼写对应 | 立通路 | 看到例词能读、听音能逐字母写出；最小对立对（ship/sheep、think/sink、v/w、æ/e）零失误 |
| 02 | 自然拼读法：音节划分与重音 | 切长词 | 陌生 3–4 音节词 **10 秒内**给出音节划分与重音并读出 |
| 03 | 词根词缀拆解法 | 拆长词 | 陌生学术词拆解成功率 ≥70%；词性判断 ≥90%；完成「拆解→猜义→核对」闭环 |
| 04 | 语境记忆法 | 存主通道 | 每个新词带 ≥1 个真实搭配块；能为它造 2 个不同场景的句子 |
| 05 | 联想记忆法 | 存拐杖 | 能为难词当场造三要素齐备的联想，**并且会撤掉它**；联想占比 ≤ 生词量 30% |
| 06 | 间隔重复法 | 排复习 | 会执行「回忆→揭示→自评」并诚实自评；能排出自己的 1/3/7/14/30 表 |
| 07 | 主动输出法 | 调用 | 词→短语→句→段四级漏斗逐级过关；造句通过率 ≥80% |
| 08 | 元认知训练 | 总复盘 | 三张清单 + 信号表落地；错题 100% 带归因；能说出自己最弱的 2 个环节 |

- **实验室 = 训练场**：大题量、重复练。每课对应关系固定：

|------|----------|

| 06（回忆训练） | 各课出门条 + 实验室任一 tab 的「遮住再回忆」模式（新设，见决策点 5） |

## 2. 通用设计规则（8 门课共用）

### 2.1 短单元机制

- 每课拆 **5–6 个单元**，单元时长 **5–9 分钟**，单元间可随时停（随用随开）。
- 课与课之间进度仍为内存态、刷新归零（约束不变）；单元是新的最小完成单位。
- 旧「8 步」全部废弃；**每课单元的内部环节不强制统一**（有的课单元以演示为主，有的以做题为主），只有微观节奏建议：进单元 → 动手 → 收一句。

### 2.2 密度规范（针对文字密度大）

每个单元的讲解文本收敛为三件套，UI 阶段将按此分层排版：

- **主张**：一句话，≤40 字，先给结论。
- **例子**：一个，能被交互演示替代的交给演示。
- **动作**：一道题 / 一次点击 / 一句跟读——单元必须以动手收尾。

超过三件套即视为「该拆单元」。旧文案中正确的规则、例词、误区作为**素材保留**（事实不重造），表达全部重写。

### 2.3 开场与收尾设备

- **开场 = 诊断（1 分钟做题）**，替代「方法登场」空话：先暴露弱点，本课的价值当场成立。每课诊断题型不同（见 §3）。
- **收尾 = 出门条（exit ticket）**：6–10 题快测覆盖本课可观察目标，当场判分 + 一句人话诊断（如「你的裂缝在 θ/s 辨音」）。不持久化，刷新即消失——文案如实说明。
- 旧「掌握标准」清单改造成**离场自测卡**：每条改写为可自问自答的是/否句，展示在出门条之后。

### 2.4 数据 schema 方向（为重写预留）

```ts
type Course = {
  id; title; subtitle; stage;            // stage: 'pathway' | 'storage' | ... 路径分段
  goal: string;                          // 可观察目标（一句话）
  durationMin;
  opening: Diagnostic;                   // 诊断开场（题型 + 分数解读）
  units: Unit[];                         // 5–6 个，形状每课不同
  exitTicket: Question[];                // 出门条
  selfCheck: string[];                   // 离场自测卡（是/否句）
  labLinks: { unitId; target: LabTab }[];
};

type Unit = {
  id; title; durationMin;
  claim: string;                         // 一句主张（≤40字）
  blocks: Block[];                       // 类型化内容块：example | demo | warning …（不再是一整段 text）
  practice?: PracticeRef;                // 可选：微练习（新题型或复用现有）
  check?: string;                        // 可选：收口自检一句话
};
```

要点：`blocks` 类型化（终结纯文本墙）、`practice` 每课可不同（终结 StepAnimation 固定分发）、诊断/出门条是一等公民。

## 3. 逐课大纲

### 01 音标发音与拼写对应 —— 「双通道焊接」

**诊断开场**：10 题混合测（4 听音选音 + 4 看词读音 + 2 最小对立），产出「你的三条裂缝」报告，本课按裂缝排序建议路线。

| 单元 | 时长 | 干什么 | 练习形式 |
|------|------|--------|----------|
| U1 起点自测：你的三条裂缝 | 6′ | 诊断 + 报告解读：错在听觉维度还是对应维度 | 诊断测试（新题型①） |
| U2 音标 = 动作，不是符号 | 8′ | 48 音按发音部位归成 5 个动作家族，代表音口型动画模仿；核心：动作对了，符号只是标签 | 看动画做动作 → 听音自检（复用口型动画） |
| U3 最小对立对：焊四条中文裂缝 | 8′ | ship/sheep、think/sink、v/w、æ/e 逐对攻；每对讲清「动作差在哪」 | 听觉二选一（复用 minimalPair） |
| U4 通路 A：形 → 音 | 7′ | 高频拼写对应规则（th / ph / -tion / soft g），看词能读 | 看词选音（复用）＋ 深链 `/lab/mapping` |
| U5 通路 B：音 → 形 | 7′ | 听音落笔，错题标注「错在哪个维度」 | 逐字母听写（复用）＋ 深链 `/lab/dictation` |
| U6 合流出门条 | 6′ | 双向翻牌限时配对 + 出门条 8 题 + 离场自测卡 | 双向翻牌（新题型②）+ 出门条（新题型⑬） |

**与实验室**：U2–U3 深链 `/lab/phonemes`；本课是全站唯一系统教音标的课，实验室承担全部题量。

### 02 自然拼读法：音节划分与重音 —— 「划词算法」

**诊断开场**：给 decision，先按你现在的习惯划音节 + 点重音，当场对照 /dɪˈsɪʒn/ 揭晓，测出「从没数过元音核心」这一根因。

**本课专属结构 = 算法递进**：一条三步算法（数元音核心 → 分辅音 → 定重音），每个单元给算法**加一步**并立刻跑题，最后一单元用完整算法连跑通关——课程本身就是一台逐步组装的机器，与 01 的双通道、03 的流水线形状都不同。

| 单元 | 时长 | 干什么 | 练习形式 |
|------|------|--------|----------|
| U1 逐字母背为什么崩 | 5′ | decision 逐字母 vs 按块对比 + 诊断揭晓 | 划词自测（诊断） |
| U2 算法步 1：数元音核心 | 8′ | 元音核心计数器（含 y、-tion 整体一块两个特例） | 圈元音核心（新题型③） |
| U3 算法步 2：分辅音 | 7′ | 「让后一个音节能读出来」原则 + str 家族演示 | 拖槽划音节（复用 syllableSplit） |
| U4 算法步 3：定重音 | 8′ | 后缀 / 词性 / 词根三线索；record 名动对比 | 点选重音（复用 stressPosition） |
| U5 焊点：-tion / -sion 家族 | 6′ | 与 01 课联动，音形对应在音节上的兑现 | 家族听写（复用） |
| U6 长词通关 + 出门条 | 8′ | 算法连跑 10 个生词计时（transportation、incomprehensible…）+ 出门条 | 算法跟跑计时（新题型④）+ 出门条 |

**出门条**：陌生四音节词 ×3 现场划分 + 标重音；离场自测卡 5 条。

### 03 词根词缀拆解法 —— 「零件流水线」

**诊断开场**：contradiction 当场拆（能拆成几块？），测「见词敢不敢拆」。

**本课专属结构 = 流水线**：零件库（前缀/词根/后缀三条送料线）→ 组装 → 质检（防假词素）→ 出货（闭环核对）。与 05 的手作工坊刻意区分：这里是可重复的机械流程。

| 单元 | 时长 | 干什么 | 练习形式 |
|------|------|--------|----------|
| U1 生词拆解秀 | 5′ | contradiction 拆开三块 → 诊断 | 拆解自测（诊断） |
| U2 送料线 A：前缀定方向 | 8′ | 24 高频前缀归 6 个语义家族（否定/时空/趋向…） | 前缀–词义配对（复用 affixAssemble 变体） |
| U3 送料线 B：词根定核心 | 8′ | 30 高频词根按意象族记（spect 看 / dict 说 / port 运…），词族树从 1 根长 5 词 | 词族树生长（新题型⑤） |
| U4 送料线 C：后缀定词性 | 7′ | -tion 名 / -ize 动 / -ly 副 + -ation 重音规则（联动 02 U4） | 词性判断（复用） |
| U5 质检：假词素与同化前缀 | 8′ | condition 拆错示范；im-/il-/ir-、com-/col- 认亲 | 真假拆解判别（新题型⑥） |
| U6 出货：拆解→猜义→核对闭环 | 8′ | 3 个陌生词完整闭环计时，核对时回答「语义跳跃在哪」 | 闭环计时（新题型⑦）+ 出门条 |

**数据**：复用 `affixes.ts` / `rules.ts` / `words.ts`，只重写组织与文案。

### 04 语境记忆法 —— 「句中求生」

**诊断开场**：读 The ship was visible from the shore. —— visible 认识但句子能不能秒懂？测「背过 ≠ 读得懂」。

**本课专属结构 = 案发现场**：每单元围绕一个真实句子「打捞」——圈块、辨义、造句、排假语境；主语始终是句子，不是单词（其余 7 课主语都是词或符号，本课形状天然不同）。

| 单元 | 时长 | 干什么 | 练习形式 |
|------|------|--------|----------|
| U1 背过但用不了 | 5′ | visible 测试 + 诊断揭晓 | 句读理解自测（诊断） |
| U2 字典义 ≠ 用法义 | 8′ | refuse 双句型、make up 多义；同一词在不同搭配里的样子 | 语境选义 / 语境选词（复用 contextChoice） |
| U3 打捞搭配块 | 8′ | 句中三色圈块：搭配 / 修饰 / 介词块；整块朗读把节奏也编码 | 句中圈块（新题型⑧） |
| U4 造句三问 | 8′ | 搭配对？词性对？像真人会说的话？——自检后才算过 | 造句自检台（新题型⑨） |
| U5 排雷：假语境与中文迁移 | 7′ | I use the word visible. / learn knowledge ✗ 的病灶解剖 | 假语境找茬（新题型⑩） |
| U6 实战：把 plant 种进两个场景 + 出门条 | 7′ | 一词多义的语境决定义项；两个场景各造一句 | 造句 + 出门条 |

### 05 联想记忆法 —— 「手作工坊：造 · 质检 · 拆」

**诊断开场**：ambulance 你怎么记的？（谐音？画面？抄词表？）——揭示你已经在用的方法及其断点。

**本课专属结构 = 工坊三工序**：制造（造联想）→ 质检（三要素查表）→ 拆（撤脚手架）。本课的终点不是「会造」而是「会拆」——这是全站唯一以「拆除自己的工具」收尾的课，形状独有。

| 单元 | 时长 | 干什么 | 练习形式 |
|------|------|--------|----------|
| U1 俺不能死 | 5′ | ambulance 全链演示：发音→画面→句子收回 | 记录你的记法（诊断） |
| U2 为什么画面粘：三条路径 | 7′ | 字形→义 一条路 vs 形/音/画 三条路互备 | 路径对比题（选择） |
| U3 质检表：音近 · 义通 · 动感 | 8′ | 三要素逐项打分，缺一环就「想起画面想不起词」 | 坏联想找茬（新题型⑪） |
| U4 当堂制造 | 8′ | 3 个难词自造联想，写下来 + 三要素自勾 | 开放输入 + 自检勾选（新题型⑨变体） |
| U5 回收仪式：撤脚手架 | 7′ | 画面→发音→句子收回；48 小时还原 / 一周撤拐预告 | 撤拐测试：不看画面直接反应词义 |
| U6 边界：什么时候不造联想 + 出门条 | 5′ | 高频词、简单词直接多读多用；占比 ≤30% 原则 | 判别题（造/不造）+ 出门条 |

**判分说明**：造联想是开放输入，站内不做对错判定——用三要素自检表 + 参考范例对照，符合零外部依赖（即便 CDN 已放开，也不引入文本 AI 判分）。

### 06 间隔重复法 —— 「排期员」

**诊断开场**：上周学的词，现在默写三个——测「你有没有复习系统」。

**本课专属结构 = 排期表**：读懂曲线 → 找甜点 → 上岗演练（回忆-揭示-自评）→ 生成你的时刻表。课程产出物是一张表，不是一串技能。

| 单元 | 时长 | 干什么 | 练习形式 |
|------|------|--------|----------|
| U1 同样学 1 小时，7 天差 3 倍 | 5′ | 遗忘曲线先陡后平 + 默写诊断揭晓 | 默写诊断 |
| U2 甜点：合意难度 | 7′ | 在曲线上找「遗忘 30%」的位置；太轻松/太贵都亏 | 最佳复习时机选择（新题型⑫） |
| U3 回忆 ≠ 重读 | 8′ | 主动回忆演示：合上书 vs 看一遍的提取力差 2–3 倍 | **回忆→揭示→自评**三拍练习（新题型⑬，全站核心新交互） |
| U4 排期规则：1/3/7/14/30 | 8′ | 升档 / 降档规则，为什么是这五个间隔 | 排期决策题（给情境选动作） |
| U5 假复习甄别 | 7′ | 重读错觉、虚报「记得」、一次刷 50+ 卡的代价 | 情境判别（选择） |
| U6 交接：你的复习时刻表 + 出门条 | 6′ | 按规则排出一张样表 + 明确「站内不存储，这是学排法的样表」 | 排表 + 出门条 |

**诚实说明**：零存储约束不变，站内排期仅本会话有效——课程教的是「排法」，文案不假装帮你存。

### 07 主动输出法 —— 「四级漏斗」

**诊断开场**：transformation——现在用它造一个句子（不是默写）。测「认识 ≠ 想得起用」。

**本课专属结构 = 漏斗**：L1 听写 → L2 搭配 → L3 造句 → L4 复述，逐级收窄、逐级强制产出，每级过不去不放行——全站唯一一门「每单元都在产出」的课。

| 单元 | 时长 | 干什么 | 练习形式 |
|------|------|--------|----------|
| U1 不会用 = 没学会 | 5′ | 被动/主动词汇 1/5 转化率 + 造句诊断 | 造句诊断 |
| U2 生成效应：为什么说错也有用 | 7′ | 自己产出的信息比读到的牢；输出自带反馈 | 判别：哪种练法算输出（选择） |
| U3 漏斗 L1–L2：听写与搭配 | 8′ | 音→形输出 + 固定搭配块（under construction） | 听写（复用）+ 搭配补全（新题型⑭） |
| U4 漏斗 L3：造句 | 8′ | ≥4 词强制；三查：含目标词 / 语法对 / 像真人话；**安全句拦截器** | 造句自检台（新题型⑨）+ 安全句识别 |
| U5 漏斗 L4：复述 | 8′ | 3 句话概括一段文字 / 含目标词的小故事；支架给开头句 | 复述支架（新题型⑮） |
| U6 配比：每天 15 分钟 + 出门条 | 6′ | 5′朗读 + 5′造句 + 5′复述的可执行配比 | 制定配比 + 出门条 |

### 08 元认知训练 —— 「仪表盘」

**诊断开场**：回想你最近一次错题——为什么错？说不出 = 没有仪表盘。

**本课专属结构 = 读盘→认信号→练归因→开一次真盘**：本课是全路径的收官——前 7 门积累的练习数据在这里第一次被「使用」，所以它必须最后上，且最后一单元是真复盘不是模拟。

| 单元 | 时长 | 干什么 | 练习形式 |
|------|------|--------|----------|
| U1 100 道题的两种人 | 5′ | 差别在复盘不在题量 + 错题归因诊断 | 归因自测（诊断） |
| U2 三张清单 | 8′ | 学前计划 / 学中监控 / 学后复盘——把感觉变成勾选 | 填清单（新题型⑯） |
| U3 信号表：出现 X 就做 Y | 8′ | 听写<60% → 回实验室练最小对立对；复习积压 → 新词减半 | 信号–动作配对（新题型⑰） |
| U4 归因训练 | 8′ | 知识缺口 / 粗心 / 时间不足三分类；「我不行」→「方法不对」 | 错因归类（新题型⑱） |
| U5 真实复盘实操 | 8′ | 拿你刚才诊断与练习的真实错题开一次复盘 | 复盘表填写（新题型⑲） |
| U6 毕业：给自己的方法写一条改进 | 5′ | 收官仪式 + 出门条 + 总自测卡 | 写改进条 + 出门条 |
